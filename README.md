# Кофейный котик — лабораторная работа 5

Учебный сайт кофейни на HTML, CSS и JavaScript. Исходник скопирован из проекта лабораторной работы 4; исходная папка сохранена без изменений.

## Опубликованный сайт

https://koekak715.github.io/coffee-cat-git-lab05/

Сайт опубликован через GitHub Pages из корня ветки `gh-pages`. Доступность HTML, CSS, JavaScript и всех изображений проверена. Ветка публикации содержит только файлы из `site/`.

## Локальный просмотр

Откройте `site/index.html` или запустите из корня проекта:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Адрес: `http://127.0.0.1:8000/site/`. Это локальный просмотр, не публикация сайта.

## Проверки

```sh
node --check site/script.js
python tools/check_site.py
node --test tests/site.test.cjs
```

Зависимости для сборки не нужны. CI проверяет структуру страницы, локальные ресурсы, синтаксис JavaScript и поведение интерфейса в изолированной модели DOM. Workflow `Site CI` не выполняет развёртывание. Публикацией из ветки `gh-pages` управляет стандартный механизм GitHub Pages.

## Ветки

- `main` — актуальная проверенная версия;
- `feature/coffee-guide` — три фотографии из рабочей папки и мини-гид по кофейной паузе;
- `fix/accessibility-menu` — читаемость, фильтры и доступ к составам;
- `ci/site-checks` — автоматические проверки при push и pull request.
- `gh-pages` — файлы опубликованного сайта в корне ветки.

История фиксирует начальную копию ЛР4 и отдельные изменения. Все сведения о кофейне демонстрационные. Происхождение фотографий описано в `IMAGE_SOURCES.md`.
