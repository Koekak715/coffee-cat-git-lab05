# Происхождение фотографий

Все восемь исходных JPG взяты из доступной рабочей папки ЛР4 `coffee-cat/dist/assets`. В README исходного проекта указан источник Unsplash. Индивидуальные страницы и авторы исходных загрузок не сохранены, поэтому персональная атрибуция не выдумывается. Лицензия сервиса: https://unsplash.com/license (проверена 01.11.2026). Сведения о происхождении основаны на README ЛР4, а не на независимом установлении авторства каждого снимка.

Для нового блока мини-гида добавлены три локальных файла. Это повторное использование фотографий ЛР4 в новом разделе, а не новые авторские снимки:

| Файл | Источник в ЛР4 | Содержание |
| --- | --- | --- |
| `site/assets/guide-brewing.jpg` | `hero.jpg` | Ручное заваривание кофе через фильтр |
| `site/assets/guide-window.jpg` | `cafe.jpg` | Столик у окна с растениями |
| `site/assets/guide-iced.jpg` | `latte.jpg` | Холодный кофе со льдом в стакане |

Байты копий совпадают с исходниками; контрольные суммы фиксируются в материалах отчёта. В HTML используются относительные пути. Внешние ссылки на изображения и обращения к сервису фотографий при просмотре не нужны. Снимки используются как иллюстрации концепта, а не как подтверждение существования реальной кофейни.
